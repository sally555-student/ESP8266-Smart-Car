# ESP8266-Smart-Car# ESP8266 Smart Car

An embedded systems project based on the ESP8266 microcontroller,
designed to control a smart car and implement obstacle detection
and remote/voice-based control.

## Features

- ESP8266-based control
- DC motor control
- Ultrasonic obstacle detection
- Buzzer alert
- Voice-based commands
- Embedded programming

## Hardware

- ESP8266
- Ultrasonic sensor
- DC motors
- Motor driver
- Buzzer
- Car chassis

## Software

- Arduino IDE
